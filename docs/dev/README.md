# Developer notes

| File | What it is |
|---|---|
| `DECISIONS.md` | Design and engineering decisions with the reason for each |
| `API.md` | Internal contract between the UI and `lib/` |
| `QUESTIONNAIRE_SPEC.md` | Design spec for the adaptive questionnaire, fact families and i18n platform |
| `SECURITY_AUDIT.md` | Internal security review and the regression tests it produced |
| `ai-in-product.md` | Notes on how AI providers are used and what they receive (some items still marked to complete) |
| `design-v5.md` | The visual system: material, motion and page-by-page notes |

Evaluation reports live in `eval/` (`eval/RESULTS.md` is the summary).
